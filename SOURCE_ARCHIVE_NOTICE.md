# Reconstructed Explorer 18.8.2 source archive

This archive is **not the original 18.8.2 source tree**. The original source archive was not
preserved in the workspace; the available 18.8.2 artifact is the signed APK at
`/home/user/Explorer-18.8.2/Explorer-18.8.2.apk`.

This is a best-effort, buildable reconstruction derived from the nearest available Explorer source
tree. Its metadata is set to version code 36 / version name 18.8.2, the tab-bar long-press changes
introduced for 18.8.4 have been removed, and the 18.8.2-style selector thumb structure is included.
Other historical differences from the original 18.8.2 source may remain.

The archive intentionally excludes local signing credentials, `local.properties`, Gradle caches, and
build outputs. It is provided for source inspection and reconstruction, not as a provenance claim
for the original release source.
